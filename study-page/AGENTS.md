## 필수 컨벤션

- C++17, 명시적인 표준 헤더, `using namespace std;`, 4칸 들여쓰기. `bits/stdc++.h`를 쓰지 않습니다.
- 주요 입력·배열·그래프·DP는 전역변수에 둡니다. 루프 인덱스·크기·임시값은 지역변수로 둡니다. 전역 상태는 매 실행 초기화합니다.
- 일반 함수 중심으로 작성합니다. 간선·큐 상태에 여러 의미의 필드가 필요하면 `struct edge` 또는 `struct node`를 씁니다. 세그먼트 트리도 클래스를 쓰지 않습니다.
- `N, M, K, nums, edges, dist, dp, cnt, ans, now, next, left, right, idx, len`처럼 짧고 익숙한 이름을 사용합니다.
- 입력 범위를 먼저 정합니다. 그 범위가 int에 들어가면 크기와 인덱스는 int를 사용하고 `int len = nums.size();`처럼 저장합니다. 빈 배열의 `len - 1`은 len을 int로 받은 다음 계산합니다.
- 기본 템플릿에 `size_t`, `unsigned`, `static_cast`, `numeric_limits`, 복잡한/재귀 람다, 중첩 pair, 구조적 바인딩을 관성적으로 넣지 않습니다. 단순 pair·반복자·범위 for는 의미가 분명하면 사용할 수 있습니다.
- 합·거리·곱이 int 범위를 넘는 곳에는 `using ll = long long;`과 ll을 씁니다. 값이 int 범위라면 간선 끝점·가중치까지 ll로 뭉뚱그리지 않습니다. `1LL * a * b`처럼 계산 **전에** 필요한 승격은 유지합니다.
- INF는 명시적 정수 상수입니다. 각 문서에 최대 유효값·중간 계산과 INF의 관계를 짧게 설명합니다. INF에서 더하지 않으며 음수 사이클 등 중간 계산도 ll을 넘지 않는 전제를 확인합니다.
- 문자열 기본 예제는 ASCII(0~127), `char`, 빈도 배열로 작성합니다. 임의 바이트·유니코드 디코딩을 일반화하지 않습니다.
- 비트마스크 기본 예제는 N <= 20의 int와 `1 << i`를 사용합니다. 더 큰 예제는 범위를 명시하고 필요할 때 ll·`1LL << i`를 사용합니다. unsigned의 64비트 전체 범위는 필요할 때 별도 심화 예제로만 다룹니다.
- 범위·empty 검사, 초기화, 오버플로우 방지, 알고리즘 정당성을 스타일 교정 때문에 제거하지 않습니다. 예외가 필요하면 해당 코드·설명에 이유를 명시합니다.

## 변경과 검증

- 기존 풀이 원본은 읽기만 합니다. `src/data/solutions.json`의 내 풀이 원문도 스타일 교정 대상이 아닙니다.
- 전체 코드와 부분 코드는 `templates/*.cpp`를 기준으로 표시합니다. 템플릿을 고치면 설명의 변수·전제·행 범위·추적표·시각화 해석을 함께 수정합니다.
- 세 시각화는 수정된 C++에서 `python3 scripts/generate-traces.py`로 기록을 다시 만듭니다. JavaScript에 별도 알고리즘 구현을 만들지 않습니다.
- `npm run check`, 독립 헤더 컴파일, `python3 scripts/check-cpp.py`, `python3 scripts/generate-traces.py --check`, 웹 빌드와 브라우저 검사를 실행합니다. 예제·빈 입력·경계값·재호출·int를 넘는 합/거리/곱을 확인합니다.
- Windows 의존성 `node_modules`와 `start.cmd`를 보존합니다. WSL의 Linux 검증은 필요하면 임시 복사본을 사용합니다. 실행·구조·기능을 불필요하게 바꾸지 않습니다.

## 공부 노트 문체

- 본문·소제목·변수 설명·반례·표·그림 설명·시각화 안내에 같은 문체 적용.
- 기본 문장은 짧게: `0으로 초기화`, `문자 추가`, `while 종료 후 답 갱신`, `bb가 남으므로 while 필요`.
- `~합니다 / ~입니다`를 반복하거나 어미만 잘라내지 말 것. 주어·동작·이유를 다시 정리해 자연스러운 공부 메모로 작성.
- 추상적인 `원소 반영`, `조건 복구`, `해당 시점에 수행` 대신 실제 코드 동작 명시. 예: `cnt[now]++로 문자 추가`, `중복이 없어질 때까지 왼쪽 문자 제거`.
- 소제목도 짧고 구체적으로: `오른쪽 문자 추가`, `중복 제거`, `최대 길이 갱신`.
- 코드가 하는 일은 짧게, 순서가 필요한 이유는 인과관계로 연결. 조건·변수·범위를 먼저 밝히고, 순서를 바꾸면 틀리는 입력을 함께 기록.
- `이제 살펴보겠습니다`, `중요한 점은`, `이해할 수 있습니다` 같은 도입·마무리 삭제. 모든 문장을 `~함`으로 끝내거나 명사만 나열하지 말 것.
- 짧게 쓰려고 정당성·경계값·오버플로우 근거·반례를 생략하지 말 것. 예: `abb에서 a만 빼면 bb가 남으므로 if 대신 while로 반복`.
- 문체 교정에서는 C++ 원문·예제 입력/출력·시각화 실행 기록을 유지. 수정 전후 해시로 이를 확인하고 설명·화면·검색·복사·단계 안내를 검증.

- 문체 점검은 실행 순서 본문뿐 아니라 요약·선택 조건·최적화 과정·정당성·복잡도·오답 표·추적표·검색 결과·빈 결과·복사 안내·출처 설명까지 포함. 출처의 사실·URL·난이도·확인 날짜와 기존 풀이 코드는 보존.
- 주제 요약을 바꾸면 catalog의 검색·목록 요약도 함께 갱신. 구간 표기는 템플릿의 닫힌/반열린 정의와 일치시키기.

## 설명 속 코드·수식 간격

- 본문·조건·변수 표·오답·추적표·그림·공통 노트·시각화 안내에도 실제 C++ 코드와 같은 간격 적용. `tin[now] = timer`, `1 <= N <= 200000`, `right - left + 1`처럼 이항 연산자 양옆에 공백.
- 대입·비교·산술·논리·비트 연산과 복합 대입에 동일하게 적용. 예: `cnt >= need`, `1LL * a * b`, `mask |= (1 << idx)`, `i += i & -i`.
- 쉼표 뒤에는 한 칸. `fill(cnt, cnt + 128, 0)`, `[left, right)`, `nums = [1, 2, 3]`처럼 함수 인자·구간·배열·연속 설명 모두 적용. 제어문은 `if (조건)`, `while (조건)` 형태.
- `timer++`, `cnt[next]--`, `-1`, `!dq.empty()`, `~(1 << idx)`, `it->second`, `node::operator<`, `vector<int>`는 각각 후위·단항·멤버·타입 표기이므로 이항 연산자처럼 나누지 않기. 수학의 거듭제곱 `2^N`과 관용 이름 `0-1 BFS`, `0/1 배낭`도 구분.
- 설명 수정 때문에 변수명·숫자·문자 리터럴·조건·URL·원본 풀이를 바꾸지 않기. 시각화 입력·선택지 간격은 표시할 때 정리하고 실행 기록은 보존.
