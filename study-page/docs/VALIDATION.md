## 재검증

```sh
npm run sync
npm run check
npm run build
python3 scripts/check-cpp.py
python3 scripts/check-originals.py
npx playwright install chromium
npm run test:browser
```

C++ 검증에는 Python 3와 g++가 필요합니다. 브라우저 검증은 기본적으로 별도 Vite 서버를 자동 실행합니다. 이미 실행 중인 서버는 `STUDY_BASE_URL`로 지정할 수 있습니다.

## 정보 범위와 제한

- 내 풀이 211개: 백준 155, 정올 15, LeetCode 23, 프로그래머스 18. 임시 코드 파일과 학습 범위 밖 최대유량 파일은 목록에서 제외했습니다.
- 난이도 185개 확인: LeetCode·프로그래머스·정올 56개는 공식 원문/API, 백준 129개는 출처를 남긴 공개 목록·제출 기록입니다. 백준 26개는 직접 조회 제한으로 원문/난이도를 확인하지 못해 추측하지 않고 미확인으로 표시했습니다. 백준 기록은 현재 등급과 다를 수 있습니다.
- `15481_트리와+쿼리.cpp`와 `1022_유기농+배추.cpp`는 파일명 번호가 내용과 달라, 원본 파일을 유지하고 각각 15681/1012의 검증된 문제 정보를 표시합니다.
- Git을 실행할 수 없어도 `data/repository.json`의 확인된 커밋·추적 파일 목록으로 기존 GitHub 링크를 유지합니다. 새 파일의 Git 상태는 Git 사용 가능 시 반영됩니다.

## Windows 실행 지원 보완

사용자가 제공한 PowerShell 오류는 `npm.ps1` 실행 정책 차단입니다. README에서 `npm.cmd`를 사용하도록 수정하고 `start.cmd`를 추가했습니다. 런처의 Node 버전 검사·설치 분기·Windows용 Rollup 잠금 항목·CMD 줄바꿈을 확인했습니다. 이 WSL 환경에서 Windows 런처의 네이티브 실행은 검증하지 못했습니다. 웹 콘텐츠와 실행 정책은 변경하지 않았습니다.
