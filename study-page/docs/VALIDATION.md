## 재검증

Windows에서는 아래 `npm` 대신 `npm.cmd`를 사용하면 PowerShell 실행 정책을 변경할 필요가 없습니다.

```sh
npm run check
npm run build
python3 scripts/check-cpp.py
python3 scripts/check-variants.py
python3 scripts/check-originals.py
python3 scripts/generate-traces.py --check
npx playwright install chromium
npm run test:browser
```

템플릿을 수정했다면 `python3 scripts/generate-traces.py`로 세 시각화 기록을 다시 생성합니다. `npm run check`가 오래된 코드 해시와 잘못된 행 범위를 검출합니다. 브라우저 검사는 별도 Vite 서버를 자동 실행하며 `STUDY_BASE_URL`로 빌드 미리보기 주소를 지정할 수도 있습니다.

검증은 WSL에서 Windows용 기존 `node_modules`를 보존하기 위해 `/tmp`의 같은 소스 복사본에 Linux 의존성을 설치하여 수행했습니다. 최종 빌드도 프로젝트의 `dist/`에 반영했습니다. Windows `start.cmd`의 네이티브 실행은 이 환경에서 검증하지 못했으며 기존 런처는 수정하지 않았습니다.
