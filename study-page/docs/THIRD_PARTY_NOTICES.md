# 문제 메타데이터 출처

LeetCode 공개 API, 프로그래머스 문제 원문 data-challenge-level, 정올 원문 og:title에서 제목·난이도를 확인했습니다(2026-10-21).

백준의 solved.ac 직접 요청은 HTTP 403, 원문은 HTTP 404였습니다. 확인 가능한 항목은 아래 공개 데이터 및 BaekjoonHub 제출 기록의 등급을 사용하며 UI에서 기록임을 구분합니다. 추가 확인일: 2026-10-22. 확인하지 못한 항목의 난이도·문제 URL은 추측하지 않습니다.

출처: https://github.com/tony9402/baekjoon/blob/main/scripts/database.json

보조 출처: https://github.com/sangilji/codingTest — 문제별 README의 제목·링크·난이도 사실 정보만 사용했습니다. 각 문제 정보에 직접 출처를 기록했습니다.
